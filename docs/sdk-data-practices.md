# 隐私政策中的AppCan SDK披露模板

> 适用版本：AppCan iOS 4.7.49｜2026-11-09

**使用位置：您自己的隐私政策网页 → “第三方SDK”章节。** 替换`【】`，删去未启用的功能段；这段是SDK披露内容，不是整份隐私政策。[返回上架填写模板](app-store-submission-guide.md)。

引擎本身填写下方基础段，并按实际启用情况保留推送等功能段。相机、位置、麦克风等权限及其数据用途，需根据所用插件或业务实际调用另行补充，不因使用AppCan引擎就全部声明。

## 隐私政策中的SDK披露模板

```text
SDK名称：AppCan iOS引擎
版本：4.7.49
提供方：【所用SDK版本对应的提供方主体名称】
用途：提供应用网页容器、网页与原生能力交互及窗口管理。
本地处理：根据页面及功能设置保存语言选项、Cookie、网页存储和缓存。
提供方说明/隐私政策链接：【经确认的有效URL】

【启用引擎推送时保留】
为提供消息推送，应用向【接收方名称】发送推送设备标识及派生标识
（deviceToken、softToken），用于【消息投递等实际用途】。
如启用账号绑定，还会处理【用户ID、昵称等实际字段】；
如启用消息统计/已读上报，还会处理【消息标识、阅读状态等实际字段】。
保存期限：【实际期限或确定方式】。
停止接收或解除绑定：【实际操作入口】；历史数据删除方式：【入口及处理方式】。

【使用其他插件时保留，并逐个填写】
插件名称及版本：【如uexCamera、uexLocation等及实际版本】
提供方：【主体名称】
用途：【实际使用的插件功能，如拍照、定位、扫码或录音】
数据项：【实际字段】；接收方：【名称】；保存期限：【期限】。
隐私政策链接：【有效URL】。
```

提供方主体、服务端用途与留存没有适用于所有客户的统一值，需由相应提供方确认。其他插件及H5第三方服务按实际使用情况另列。

## 对照表：哪些内容需要保留

| 使用情况 | 已核对行为 | 模板处理 |
| --- | --- | --- |
| 仅使用网页容器 | 页面可使用Cookie、网页存储、缓存；H5可独立发起请求 | 保留基础段，另外填写H5自身的数据行为 |
| 引擎推送 | 按配置发送deviceToken、softToken、应用/租户信息；绑定含用户字段，统计/已读含消息或状态字段 | 保留推送段，按实际分支填写 |
| uexCamera / uexScanner | 拍照或摄像头扫码使用相机；从相册选图另按实际读取方式确认 | 填写实际用途；图片或扫码结果如上传，补充接收方与保存期限 |
| uexLocation | 获取位置，授权范围与前台/后台配置有关 | 填写定位目的；按实际精度、上传及留存填写数据项 |
| uexAudio | 录音功能使用麦克风 | 使用录音时填写用途；如上传录音，补充接收方与保存期限 |
| uexEMM / uexAppStoreMgr | 企业管理、账号或设备相关功能，具体字段取决于版本和功能 | 每个已启用插件单独填写 |
| 图片加载与进度提示 | 引擎内置SDWebImage、MBProgressHUD；图片请求取决于使用路径 | 如需组件列表，列明名称；图片服务端留存另行确认 |
| AFNetworking | 引擎网络迁移使用系统NSURLSession；uexAppStoreMgr使用AFN，基础宿主也有链接/嵌入配置 | 按实际包列组件，不把AFN自身写成数据接收方 |

不要保留未填写的`【】`发布；不要将哈希标识写成“完全匿名”，或将解绑写成“历史数据已全部删除”，除非已有对应事实。

商店隐私问卷见[填写模板](app-store-submission-guide.md#app隐私问卷)，包内机器清单状态见[交付说明](privacy-manifest-delivery.md)。
