# App Store上架填写模板

> 适用版本：AppCan iOS 4.7.49｜2026-11-09

**按下表找到填写位置，复制对应模板，替换`【】`，删除未使用的功能行。** 模板中的业务事实由应用方确认。

仅使用引擎时，按实际情况填写网页容器、本地存储及已启用的推送等说明，不代表需要声明相机、位置等权限。额外权限及用途应根据所用插件或H5业务实际调用补充，具体项目以对应插件说明和实际功能为准。

| 填写位置 | 使用内容 |
| --- | --- |
| App Store Connect → App → 当前版本 → App审核信息 → 备注 | [审核备注模板](#审核备注) |
| App Store Connect → App → App隐私 | [隐私问卷速查](#app隐私问卷)（勾选项，不粘贴文案） |
| 自己的隐私政策网页 → 第三方SDK说明 | [SDK披露模板](sdk-data-practices.md#隐私政策中的sdk披露模板)；网页URL填入App Store Connect的隐私政策URL栏 |
| 打包配置或宿主Info.plist → 权限用途说明 | [权限文案](#权限用途说明) |
| App Store Connect → 审核沟通/问题回复 | [答复模板](#审核问题回复) |
| 上传提示缺少PrivacyInfo.xcprivacy | [交付状态与反馈格式](privacy-manifest-delivery.md) |

## 审核备注

**粘贴位置：当前版本 → App审核信息 → 备注。** 测试账号与密码填写在同一区域的专用登录信息栏。

```text
本应用为【目标用户】提供【核心业务，如工单处理、报销审批】服务。
使用AppCan iOS 4.7.49提供WKWebView容器及原生插件能力。

审核步骤：
1. 启动后进入【页面】，使用审核登录信息中的账号登录。
2. 选择【组织/租户；不需要则删除本行】。
3. 进入【功能路径】，可使用【演示数据】体验【核心功能】。

【实际使用时保留】相机用于【用途】，入口为【页面/按钮】。
【实际使用时保留】位置用于【用途】，入口为【页面/按钮】。
账号删除入口为【路径】，处理时限为【时间】。
远程页面/子应用提供【实际功能】，内容由【运营方】维护。
```

## App隐私问卷

**填写位置：App → App隐私 → 编辑。** 以下按实际启用功能选择；H5、插件和服务端的数据一起计算。

| 实际行为 | 优先核对的数据类型 | 用途、关联及跟踪如何选 |
| --- | --- | --- |
| 上传deviceToken、softToken用于推送 | 标识符 → 设备ID | 仅用于消息投递时核对“App功能”；绑定账号时核对“与用户关联” |
| 上传用户ID、昵称进行推送绑定 | 标识符 → 用户ID；昵称按内容核对姓名或其他用户内容 | 账号绑定用途核对“App功能”；与账号绑定的数据通常关联用户 |
| 保存消息已读/交互记录 | 使用数据 → 产品交互 | 按实际用途选择“App功能”和/或“分析”；能关联设备或账号时相应声明 |
| 上传位置、照片、文件等 | 对应的位置或用户内容类别 | 按具体功能、保存及关联方式填写 |
| 仅本机保存语言、缓存或网页状态 | 单凭该行为无需勾选云端收集 | 如另有上传，再按上传数据填写 |

“是否收集”还需核对服务端是否保留数据。仅提供推送功能不自动等于跟踪；确实未用于跨公司广告跟踪或数据经纪共享时，才选择不用于跟踪。完整定义见[Apple填写说明](https://developer.apple.com/app-store/app-privacy-details/)。

## 权限用途说明

**填写位置：打包平台对应权限配置；没有该入口时，由原生打包负责人写入宿主Info.plist。** 下表是按需选用的文案示例，仅在插件或业务实际使用相应权限时填写，替换`【】`为具体业务。

| 常见插件/功能示例 | Info.plist键 | 可改写文案 |
| --- | --- | --- |
| uexCamera拍照、uexScanner摄像头扫码 | `NSCameraUsageDescription` | 用于【拍摄报销凭证/扫描工单二维码】，以便【上传报销附件/打开对应工单】。 |
| uexScanner从相册选图等读取照片功能 | `NSPhotoLibraryUsageDescription` | 用于选择照片，完成【识别图片中的业务二维码】。 |
| 保存图片到相册（按实际插件功能） | `NSPhotoLibraryAddUsageDescription` | 用于将【业务凭证图片】保存到您的相册。 |
| uexAudio录音 | `NSMicrophoneUsageDescription` | 用于录制【工单语音说明】并发送。 |
| uexLocation前台定位 | `NSLocationWhenInUseUsageDescription` | 用于在您使用【现场签到】时获取位置，完成【签到地点核验】。 |

以上为功能示例，具体权限以所用iOS插件版本、调用方式和配置为准；若启用后台定位，还需另行核对“始终允许”用途说明及后台模式，不能只套用前台定位一行。

## 审核问题回复

**粘贴位置：该版本的审核沟通回复框。** 按Apple实际问题选一段，替换后使用。

| Apple询问 | 答复模板 |
| --- | --- |
| 为什么使用网页容器？ | 本应用通过AppCan的WKWebView提供【业务功能】，并通过【实际插件能力】完成【原生交互】。审核入口为【路径】。 |
| 为什么需要某项权限？ | 【权限】用于【功能】，入口为【路径】，在用户【动作】时申请；拒绝后【实际表现】。 |
| 标识发送给谁、做什么？ | 【数据项】发送至【接收方】，用于【目的】，保存【期限】，与【账号/设备/不关联】的关系为【说明】。 |
| 远程更新或子应用是什么？ | 本应用从【来源】加载【内容及功能范围】，更新机制为【实际方式】。相关功能可从【路径】验证。 |
| 使用了什么加密？ | 本应用使用【系统TLS及其他实际加密库/算法】完成【用途】；已按实际实现核对出口合规项，【填写所需文件或豁免依据】。 |

## 遇到问题时

| 问题 | 下一步 |
| --- | --- |
| `ITMS-91061`或缺少SDK清单 | 用[反馈模板](privacy-manifest-delivery.md#缺少清单时的反馈模板)联系对应维护者 |
| iPad启动失败、黑屏或回跳异常 | 提供应用/引擎版本、设备系统、触发步骤及崩溃日志 |
| 审核无法登录 | 更新审核专用账号、组织信息和访问步骤；不要把密码写入公开反馈 |

当前4.7.49暂不新增引擎及基础库机器清单；详情见[交付说明](privacy-manifest-delivery.md)。最终业务App的隐私填写及审核按实际包确认。
